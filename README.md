# 🗺️ Landmarks - iOS App

Landmarks is an iOS application built with **Swift and MapKit** that allows users to explore different landmarks through an interactive map and detailed landmark information.

The app supports both **iPhone and iPad**, with an adaptive interface for different screen sizes.

## ✨ Features

- 🗺️ Interactive MapKit map
- 📍 Landmark locations
- 🏞️ Landmark images and information
- 🔎 Landmark selection
- 📱 iPhone support
- 🖥️ iPad adaptive layout
- 📚 Detailed landmark descriptions
- ↔️ Sidebar navigation on iPad
- 🎨 Clean and responsive UI

## 🛠️ Built With

- Swift
- UIKit
- MapKit
- Xcode
- iOS / iPadOS

## 🗺️ MapKit

The application uses **MapKit** to display interactive maps and geographical locations for each landmark.
